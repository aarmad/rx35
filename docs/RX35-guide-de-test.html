RX35 — Guide de test sur téléphone

Ce que l'application sait faire, et comment le vérifier point par point sur un vrai appareil Android.

Version 0.1.0 Fichier app-release.apk (67 Mo) Serveur rx35.onrender.com Android 6.0 minimum

1. Installer l'application

  1. Transférez app-release.apk sur le téléphone (câble USB, Google Drive, ou envoyez-le-vous sur WhatsApp).
  2. Ouvrez le fichier depuis le téléphone. Android demandera l'autorisation d'installer depuis cette source : acceptez.
  3. Si Play Protect affiche « application non reconnue », choisissez Installer quand même. C'est normal : l'APK est signé par votre propre clé, pas par le Play Store.
Deux choses à savoir avant de juger l'application

a) Le serveur s'endort. L'hébergement est gratuit : après 15 minutes sans activité, il se met en veille et la première connexion prend 30 à 60 secondes. Ce n'est pas l'application qui rame. Pour éviter l'attente, ouvrez d'abord https://rx35.onrender.com/health dans le navigateur du téléphone et attendez de voir {"ok":true}.

b) Il n'y a pas encore de boîtier ESP32. Un compte neuf n'a donc aucune mesure, et l'application affichera « Aucun relevé pour l'instant ». C'est voulu : elle n'invente jamais de chiffres. Utilisez le compte de démonstration ci-dessous, ou simulez un boîtier (section 3).

3. Simuler le boîtier depuis votre PC

Pour voir l'accueil, l'historique et les notifications se remplir sans matériel :

  1. Dans l'application : Réglages → Boîtiers → Ajouter un boîtier.
  2. La clé s'affiche une seule fois — recopiez-la.
  3. Sur votre PC, ouvrez PowerShell et collez ceci en remplaçant la clé :
# Envoyer un relevé de capteurs
$cle = "COLLEZ-VOTRE-CLE-ICI"
$corps = @{ temperatureC=31.2; humidityAirPct=58; soilMoisturePct=27;
            waterLevelPct=64; soilPh=6.3; batteryPct=91; lux=920 } | ConvertTo-Json
Invoke-RestMethod -Uri 'https://rx35.onrender.com/api/device/sensors' -Method Post `
  -Headers @{ 'X-Device-Key' = $cle } `
  -ContentType 'application/json; charset=utf-8' -Body $corps -TimeoutSec 120
# Déclencher une alerte (pour tester les notifications)
$corps = @{ type='mouvement'; message='Mouvement détecté près du portail sud' } | ConvertTo-Json
Invoke-RestMethod -Uri 'https://rx35.onrender.com/api/device/alerts' -Method Post `
  -Headers @{ 'X-Device-Key' = $cle } `
  -ContentType 'application/json; charset=utf-8' -Body $corps -TimeoutSec 120

Relancez la première commande plusieurs fois en changeant soilMoisturePct (46, puis 43, puis 39…) : la courbe de l'Historique se dessinera.

Types d'alerte acceptés : mouvement, niveau_eau, alarme, badge_refuse, info.

5. Ce qui n'est pas un bug

Mot de passe oublié : indisponible pour l'instant

L'écran existe et le mécanisme est complet côté serveur, mais aucun service d'envoi d'e-mails n'est configuré. L'application vous le dira franchement : un avertissement rouge s'affiche et le bouton reste grisé.

Pour l'activer, il faut un compte SMTP gratuit (Brevo, Resend…) et ajouter SMTP_HOST, SMTP_USER, SMTP_PASSWORD dans les variables d'environnement du serveur sur Render. Dites-le-moi et je le branche.

6. Si quelque chose ne marche pas

  1. Vérifiez le serveur : ouvrez https://rx35.onrender.com/health dans le navigateur du téléphone. Si vous ne voyez pas {"ok":true}, le problème vient du serveur, pas de l'application.
  2. Vérifiez l'adresse utilisée par l'app : Réglages → À propos.
  3. Testez le réseau du téléphone : ouvrez n'importe quel site.
  4. Si l'app se ferme toute seule, notez l'écran exact et ce que vous veniez de faire.
Pour me signaler un problème

Le plus utile, dans l'ordre : une capture d'écran, l'écran où vous étiez, ce que vous veniez de faire, et l'heure approximative (elle permet de retrouver la trace côté serveur).
